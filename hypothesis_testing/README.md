## 1. About

This project contains three small business tasks on hypothesis testing. They are in three notebooks: **loan**, **software_development**, and **price_quotes**. 

## 2. Files

Initial notebooks
- `loan.ipynb`
- `price_quotes.ipynb`
- `software_development.ipynb`

Notebook-to-pdf conversion
- `loan.pdf`
- `price_quotes.pdf`
- `software_development.pdf`

Others
- `requirements.txt`
- `README.md`

## 3. How to run

- Make sure that all requirements in `requirements.txt` are installed
- Open and run three notebooks
